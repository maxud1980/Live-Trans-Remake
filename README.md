# Live Trans — Remake

[![License: PolyForm NC 1.0.0](https://img.shields.io/badge/license-PolyForm--NC--1.0.0-blue)](LICENSE)

**A community remake of [Live Trans](https://github.com/minhnhat165/live-trans), originally created by [Minh Nhật Nguyễn](https://github.com/minhnhat165).**

This repository keeps the original project's core concept but focuses on a different UI, a subtitles-first workflow, expanded platform/audio support, and a number of fixes and improvements.

Please see the original repository for the original project's description, documentation, history and upstream implementation.

## What is different here

The main changes in this remake:

- **Subtitles-only workflow** — translated audio playback was removed. The app displays the original and translated speech as text.
- **Microphone input** — translation can use a selected microphone/input device as well as system audio.
- **Windows support** — added native WASAPI process-loopback capture.
- **Improved macOS capture** — system audio capture excludes the application's own audio process to avoid feedback.
- **Automatic reconnect and session resumption** — sessions can recover from Live API connection rotation or temporary network problems.
- **Reworked UI** — redesigned compact interface with side-by-side transcripts, settings, usage information and status controls.
- **Live input-level meter** — shows the actual source audio level.
- **Usage/cost tracking** — displays token usage and estimated session cost.
- **Encrypted API-key storage** — uses Electron safeStorage.
- **Automated builds** — GitHub Actions produces Windows and Apple Silicon macOS builds.
